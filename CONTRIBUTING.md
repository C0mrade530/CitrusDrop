# Contributing

Use Swift 5.9+ and Apple Command Line Tools. Build with `./scripts/build.sh`; run `./scripts/test.sh` before submitting a change. Real media and office checks are in `tests/` and use temporary fixtures. Keep actual source files untouched during conversion and keep menus aligned with the available codecs and filters.

Small, focused pull requests are welcome. Describe the triggering input/operation, resulting behavior and checks run. Changes to pinned engine downloads must include verified hashes, architecture/minimum macOS and publisher identity.
