# Changelog

## 0.2.0

- Distinct Convert, Tools and Actions views, explicit operation labels, selected-operation buttons, preserved format/tool choices and visible file-action results.

- Install verified free FFmpeg/FFprobe and LibreOffice engines from the app, without Homebrew or admin privileges; reuse existing compatible installations.
- Video/audio stream inspection, codec-aware menus, accurate trim, silent video handling, phone orientation, alpha/HDR-aware output and metadata tools.
- Explicit Word, Calc and Impress conversion filters; correct UTF-8 CSV/TSV import, legacy Office output, EPUB export and every-page PNG/JPEG export.
- Smaller-output checks for media, native still-image compression and PDF compression retaining the text layer.
- GitHub branding, English/Russian docs, signed-download verification and one-command application installation.

## 0.1.0

Initial native AppKit application: drag wheel, Finder selection via Shift, conversion/compression Services, batch conversion, PDF/subtitle/archive tools, preserved originals, RU/EN interface and universal source builds.
