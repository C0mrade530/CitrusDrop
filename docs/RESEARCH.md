# Исследование и самостоятельная реализация

Дата: 21 октября 2026. Продукт: CitrusDrop 0.2.0.

## Что удалось наблюдать

Пользователь прислал Instagram Reel `DerF97dMYMe` и название Tangerine. Instagram не отдал страницу (throttled), поэтому содержимое самого Reel не подтверждено. Вместо него изучены первичные публичные материалы автора:

- [Официальный сайт](https://www.tangerineformac.com/).
- [Пресс-кит](https://www.tangerineformac.com/press).
- [Публичное короткое демо](https://www.tangerineformac.com/videos/tangerine-landing-demo.mp4).

Демо просмотрено выборочным кадром: файл WAV удерживается над круговым меню, вокруг курсора расположены аудиоформаты, сектор под указателем подсвечивается. Сайт описывает разные группы операций по клавишам и локальную обработку. Это наблюдаемое поведение, а не доступ к исходникам или внутреннему устройству Tangerine.

CitrusDrop написан самостоятельно. Не использованы исходники, бинарник, закрытые API или графические ресурсы Tangerine. Не обходились лицензии и платные функции. Публичное демо не включено в дистрибутив. Название, иконка, код и оформление CitrusDrop собственные.

## Соответствие задачам пользователя

| Запрос | Реализация |
|---|---|
| MacBook | Нативный AppKit, целевая macOS 13+, universal Mach-O arm64/x86_64 |
| Бесплатно и исходники для GitHub | MIT, нет сервера/подписки/ключей; сборка и workflow в репозитории |
| Shift при перетаскивании | Мониторинг состояния мыши, модификаторов и drag pasteboard, NSPanel + NSDraggingDestination |
| Shift на выделении Finder | Опциональный короткий тап Shift, Apple Events для чтения selection с системным согласием |
| Правая кнопка на файле | Две нативные службы macOS через NSServices и servicesProvider: конвертация и сжатие |
| Выбрать формат в колесе | NSView с секторами, hover, drag/drop, кликом, стрелками, Enter и Esc; доступные кнопки для Accessibility |
| Сжать | Перекодирование изображений/аудио/видео; ZIP/TAR/TGZ для папок |
| Русский / английский | Переключатель, сохранение настройки, переводы операций, ошибок и объяснения системного разрешения |
| Футуристичный минималистичный дизайн | Графитовые поверхности, холодные линии, оранжевое главное действие, компактная нативная компоновка |

Не заявляется полное повторение всех функций оригинального коммерческого продукта. Точная поддержка и ограничения перечислены в README.

## Архитектура

- `App.swift`: жизненный цикл, status bar, окно, обработка служб Finder, запуск последовательной фоновой задачи, разрешения.
- `DropWheel.swift`: колесо, hit testing, drag destination, мышь, клавиатура и Accessibility.
- `Models.swift`: классификация файлов, обнаружение локальных движков, пересечение поддерживаемых операций, безопасные имена.
- `Converter.swift`: преобразования через системные фреймворки и внешние процессы с массивами аргументов; отмена; staging и финальное сохранение.
- `TextFormats.swift`: SRT/VTT и многостраничный текстовый PDF.
- `FinderIntegration.swift`: согласие Apple Events и чтение только путей выделенных файлов; оформление кнопок.
- `Localization.swift`: язык интерфейса и сообщений.
- `SelfTest.swift`: временные реальные фикстуры, проверки результатов и ошибок.

AppKit выбран для настоящего drag/drop и системных служб без браузерной оболочки. Колесо не требует глобального event tap. Файлы обрабатываются последовательно; пути не подставляются в shell. FFmpeg и LibreOffice обнаруживаются локально. Проверенные движки можно установить явной кнопкой приложения; командный установщик устанавливает недостающие движки по умолчанию.

Преобразование пишет во временный каталог. Финальный move не заменяет существующие файлы. Поиск свободного имени повторяется для каждого результата; конкурирующее создание такого имени приводит к ошибке, а не перезаписи. Архивы распаковываются в новый приватный каталог с защитами системного bsdtar; ссылки и специальные файлы запрещаются, временные результаты убираются при ошибке.

Перемещение — отдельное явно выбранное действие: сначала проверяются все имена назначения, при частичном сбое выполняется откат; пути, которые не удалось вернуть, показываются пользователю.

## Границы доказательств

Скомпилированный Intel slice не равен реальному запуску на Intel. Unit/fixture проверки не равны работе всех файлов и кодеков. Пункты Finder и реальные преобразования проверяются отдельно от движка. Для широкого публичного релиза нужны проверки на разных версиях macOS и машинах; ad hoc подпись не заменяет Developer ID/notarization.

## Расширение 0.2.0

Медиаконвертер выделен в `MediaConverter.swift`: проверка кодеков, потоков, ориентации, alpha/HDR, точной обрезки и фактического уменьшения размера. `OfficeConverter.swift` задаёт фильтры Writer/Calc/Impress, изолирует профили и экспортирует все страницы. `Compression.swift` использует нативные изображения и Quartz PDF. `EngineInstaller.swift` проверяет HTTPS, хеши и подписи поставщиков; `EngineSetupWindow.swift` управляет установкой без Homebrew. Офисные процессы лишены IP-доступа, макросы отключены. Собственный логотип и обложка сгенерированы для CitrusDrop; происхождение в `brand/provenance.json`.
